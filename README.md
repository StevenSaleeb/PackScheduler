# Pack Scheduler Project

## Overview
This project implements multiple custom data structures in Java, designed to support software scheduling applications. The project emphasizes object-oriented programming, exception handling, and efficient data management. Core functionality includes dynamic arrays, linked lists, recursive lists, stacks, and queues.

## Features
- **ArrayList**: A resizable array that supports adding, removing, and setting elements, with duplicate checks and automatic resizing.
- **LinkedAbstractList**: A linked list with capacity limits, supporting standard list operations.
- **LinkedList & LinkedListRecursive**: Singly and doubly linked list implementations with iterators and recursive methods.
- **ArrayStack & LinkedStack**: Stack implementations with push/pop operations and capacity management.
- **ArrayQueue & LinkedQueue**: Queue implementations supporting enqueue/dequeue with capacity enforcement.
- Robust exception handling: `NullPointerException`, `IndexOutOfBoundsException`, `IllegalArgumentException`, `NoSuchElementException`, `EmptyStackException`.
- Supports both iterative and recursive methods for list manipulation.
- Designed for educational purposes and understanding core data structures and algorithms.
